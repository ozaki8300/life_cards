# Recall Completion Criteria

## 1. v1 Recall の目的

Life Cards v1 における Recall / 思い出す体験の目的は、未来の自分が、昔の自分に少し戻れる時間をつくることである。

Recall は、カードの情報を効率よく閲覧するための画面ではない。Front、Comment、画像、Back Memo を手がかりに、当時の空気や心の動きへ静かに浸るための体験である。

v1 の App Store 掲載条件は、Recall が単なる詳細画面の別表示ではなく、「思い出す」を押す意味のある体験になっていることとする。

## 2. 完成条件

v1 Recall は、以下を満たした状態で完成とみなす。

- 通常のカード詳細画面とは、見た目・余白・操作量・読む速度が明確に違う。
- 起動ボタンを押してから閉じるまで、ユーザーが操作に迷わない。
- Front、Comment、画像、Back Memo への導線が自然で、カード自体が主役になっている。
- Back Memo は全文を一気に読ませる表示ではなく、「続きを読む」体験として成立している。
- 実機スマホの縦画面で、文字・ボタン・カード・Back Memo 窓が破綻しない。
- 未ログイン時とログイン済み時で、Recall 体験に不自然な差がない。
- App Store 公開前の未完成感、実験中の印象、将来構想への入口が見えていない。

## 3. v1 でやらないこと

v1 Recall では、以下を完成条件に含めない。

- Spotify 連携
- 天気 API
- 位置情報
- Deck 上映
- 贈る機能
- Reflection
- KPI 計測

これらは将来の検討対象であり、v1 の公開判断を遅らせる理由にしない。

## 4. 実機確認項目

公開前に、少なくとも以下の状態で Recall を確認する。

- iPhone 縦画面
- PC
- 画像ありカード
- 画像なしカード
- Back Memo 長文カード
- Back Memo 短文カード
- 日本語長文タイトルのカード
- 未ログイン状態で作成・表示されるカード

確認時は、表示崩れだけでなく、閉じる、カードに戻る、Back Memo を開く、スクロールする、といった一連の動きが自然かを見る。

## 5. リリース判定

最終判断では、以下の問いに対して大きな違和感がないことを確認する。

- 「思い出す」を押したくなるか。
- 押した後、すぐ閉じたくならないか。
- Back Memo を読んだ後、カード本文をもう一度読みたくなるか。
- 自分の過去に戻った感覚が、少しでもあるか。

この4つに概ね yes と言えるなら、Life Cards v1 の Recall は App Store 掲載条件を満たしていると判断する。
